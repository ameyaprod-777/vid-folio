# Videos Directory

Place your video files here. The site expects videos named:
- project1.mp4
- project2.mp4
- project3.mp4
- etc.

## Testing without videos

If you don't have videos yet, the site will display gradient fallbacks. You can also:

1. Use placeholder videos from services like:
   - https://www.pexels.com/videos/
   - https://pixabay.com/videos/

2. Or modify the video paths in:
   - `app/page.tsx` (featured projects)
   - `app/projects/page.tsx` (projects grid)

## Video format recommendations

- Format: MP4 (H.264)
- Resolution: 1920x1080 or higher
- Frame rate: 24fps or 30fps
- Keep file sizes reasonable for web (under 50MB per video)
